Official Check Request Automation

A fully automated workflow replacing manual check request processes across banking operations — improving accuracy, traceability, and audit readiness.

Banking Automation Power Platform SharePoint Jira

Overview

The Official Check Request Automation replaced a slow, error‑prone manual workflow used by branch staff to request, track, and reconcile official checks. The new system centralized requests, enforced validation rules, and provided full traceability across departments — dramatically improving accuracy and audit readiness.

The Problem

Before automation, official check requests were handled through emails, spreadsheets, and manual data entry. This created inconsistent submissions, frequent errors, and limited audit visibility. Operations staff spent hours each week reconciling mismatched data, and branch employees had no clear way to track request status.

  • No centralized system for submitting or tracking requests
  • Frequent data entry errors due to inconsistent formats
  • Manual reconciliation taking hours per week
  • Limited audit visibility and missing documentation
  • No automated notifications or SLA tracking

Approach

I designed and delivered a fully automated workflow using the Microsoft Power Platform, integrating SharePoint and Jira to create a seamless, traceable process from submission to completion.

  • Centralized SharePoint form with validation rules and required fields
  • Power Automate orchestration for routing, approvals, and notifications
  • Automatic Jira ticket creation for operations processing
  • Unique request IDs enabling end‑to‑end traceability
  • Audit‑ready logging with timestamps, approvers, and status changes
  • Reconciliation dashboard for filtering, searching, and exporting history

The Outcome

  • 45% reduction in audit follow‑ups
  • Near‑100% traceability from submission to reconciliation
  • 40% faster processing for operations staff
  • ~15 hours saved per month by eliminating manual reconciliation
  • Zero missing or incomplete requests after standardization

What I Learned

This project reinforced the importance of designing workflows that balance automation with human oversight, especially in regulated environments. I also gained deeper experience integrating low‑code tools with enterprise ticketing systems and building audit‑friendly data models.
