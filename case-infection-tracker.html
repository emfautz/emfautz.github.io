Infection Tracker

A .NET + Angular + SQL application built in early 2020 to track infections, supplies, and staffing impact across senior living communities — with cascading forms and real‑time KPIs.

Healthcare C# .NET Angular SQL

Overview

The Infection Tracker was developed at the onset of the COVID‑19 pandemic to help senior living communities monitor infection spread, supply shortages, and staffing impact. The system evolved rapidly as needs changed, eventually supporting KPIs, cascading forms, and multi‑facility reporting.

The Problem

Senior living communities lacked a centralized system to track infections, exposures, and resource needs. Early spreadsheets quickly became unmanageable, and leadership needed real‑time visibility to make operational decisions.

  • No unified system for tracking resident and employee infections
  • Manual spreadsheets created inconsistencies and delays
  • Facilities needed to report supply shortages daily
  • Leadership required real‑time KPIs across all communities
  • Forms needed to adapt as new symptoms and protocols emerged

Approach

I built a full‑stack CRUD application using .NET, Angular, and SQL Server. The system included cascading forms, dynamic fields, and dashboards that updated as new requirements emerged.

  • Developed Angular UI with cascading forms and conditional fields
  • Built .NET API endpoints for infection, supply, and staffing data
  • Designed SQL schema for multi‑facility reporting
  • Implemented KPIs such as infection counts and employee impact
  • Added exportable reports for leadership and compliance teams

The Outcome

  • Provided real‑time visibility into infection spread across all communities
  • Enabled faster decision‑making for staffing and supply allocation
  • Reduced manual reporting time by **over 70%**
  • Supported evolving clinical protocols with flexible form logic
  • Became a daily operational tool during the height of the pandemic

What I Learned

This project taught me how to build rapidly evolving systems under pressure, design flexible data models, and create UI flows that adapt to changing clinical requirements.
