Elder Care App

A .NET + Angular + Azure SQL application built as a graduate thesis project, demonstrating senior‑living workflows, HIPAA‑aware design, and the need for modern technology in long‑term care environments.

Healthcare C# .NET Angular Azure SQL

Overview

The Elder Care App was created as my graduate thesis project at the University of Louisville. The goal was to demonstrate how modern software could improve workflows in senior living communities, where outdated systems and manual processes often slow down care delivery. The project included a working application, a research paper, and a formal presentation.

The Problem

Many senior living communities rely on fragmented tools, paper forms, and legacy systems that make it difficult to track resident needs, coordinate care, and maintain compliance. These gaps create inefficiencies and increase the risk of errors in environments where accuracy is critical.

  • Paper‑based workflows slowed down communication
  • No centralized system for resident information or care tasks
  • Legacy systems lacked modern UI and accessibility features
  • HIPAA and PII compliance required careful data handling
  • Staff needed a simple, intuitive interface

Your Approach

I built a full‑stack web application using .NET, Angular, and Azure SQL. The system included resident profiles, care tasks, medication tracking, and secure authentication. The project emphasized usability, data integrity, and compliance‑friendly design.

  • Developed Angular UI with clean, accessible components
  • Built .NET API with role‑based access and validation
  • Designed Azure SQL schema for resident and care data
  • Implemented secure authentication and PII‑aware data flows
  • Created demo workflows for daily care tasks and medication logs
  • Presented findings on technology gaps in senior living

The Outcome

  • Delivered a fully functional prototype demonstrating modern senior‑care workflows
  • Showcased how digital tools can reduce errors and improve coordination
  • Highlighted compliance considerations for healthcare software
  • Received strong feedback from faculty and industry professionals
  • Provided a foundation for future healthcare‑focused development work

What I Learned

This project strengthened my understanding of healthcare compliance, full‑stack architecture, and designing user‑friendly tools for non‑technical staff. It also reinforced the importance of thoughtful data modeling and secure handling of sensitive information.
